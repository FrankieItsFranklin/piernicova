# Заметки: Piernicova (2026-10-21)

## Как выбирали вид
1. Клиент — Restauracja Piernicova, Toruń (реальный, в базе нет). Факты: `BRIEF.md`.
2. Три первых экрана (design-kb: материал → отрисовка в полную силу → показать до правок), `docs/directions/`:
   - **A «Forma piernikowa»** — тёмный орех, название выдавлено в дереве, как в торуньской пряничной форме; глазированная katarzynka, золото.
   - **B «Bon na kuchnię»** — уголь и кирпич, бронь как кухонный бон на стальной шине открытой кухни.
   - **C «Karta ze skośnikami»** — блюдо как строка ингредиентов через «/» (так написана их карта), осенняя палитра.
3. Владелец студии: «нравится A, но бон тоже» → **D = A + B** (`D-forma-bon.html`): дерево и тиснение из A, бон на латунной шине с клипсой-katarzynką из B. Из C в сайт перешли золотые «/» в описаниях блюд и фильтр по сезонным ингредиентам.
4. Скриншоты направлений: `shots/dir-*`. Первая отрисовка сайта: `shots/v1-*`; финал: `shots/final-*`.

## Что на сайте (Next.js 16, статично)
Страницы: `/` · `/menu` · `/kuchnia` · `/rezerwacja` · `/wydarzenia` · `/voucher` · `/kontakt` · 404 · sitemap · robots.

Фишки, которые есть только здесь:
- **Бон брони** (`BookingTicket`): «печатается» на латунной шине, слегка качается. Шаг 1 — день (Dziś/Jutro/…), время из часов работы этого дня (сегодня — только будущие слоты), гости, где сесть (у открытой кухни / parter / taras). Шаг 2 — данные. После отправки — печать «PRZYJĘTE» и номер. Честно: «to prośba, potwierdzimy telefonicznie».
- **Карта с фильтром по сезонным ингредиентам** (piernik, dynia, grzyby, gruszka, śliwka, ryby, bez mięsa): выбранный подсвечивает блюда, остальные приглушаются. Ссылка `/menu?skladnik=piernik` открывает уже с фильтром.
- **«Piernik nie tylko na deser»** — блюда с пряником собраны автоматически из карты.
- **Конструктор ваучера**: имя получателя и сумма появляются на «прянике» сразу при вводе.
- **Глазурь**: волнистая линия под заголовками «выдавливается» при входе в экран; katarzynka нарисована в SVG (логотип-знак, клипса бона, 404).
- Статус «Otwarte do 22:00 / jutro od 13:00» по часам каждого дня, в зоне Europe/Warsaw.
- Нижняя панель на телефоне «Zadzwoń / Zarezerwuj».
